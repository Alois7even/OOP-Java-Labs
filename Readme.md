## Library Management System

The final practical project is a console-based Library Management System.

### Features

* Add books to the library.
* Display all available book records.
* Search for books by ID.
* Borrow books.
* Return borrowed books.
* Prevent duplicate book IDs.
* Validate borrowing and returning operations.
* Use a menu to select operations.

### Object-Oriented Concepts Applied

* **Encapsulation:** Book details are stored in private fields.
* **Classes and objects:** Books and the library are represented by Java classes.
* **Collections:** An ArrayList stores the books.
* **Methods:** Operations are separated into reusable methods.
* **Control structures:** Loops and conditional statements control the program flow.

## How to Run

1. Install a compatible Java Development Kit (JDK).
2. Open the project in IntelliJ IDEA.
3. Navigate to the required laboratory's source folder.
4. Open the Java file containing the `main()` method.
5. Run the program.

For the Library Management System, run `LibraryMenu.java`.
